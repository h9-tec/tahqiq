Method in one paragraph

Every system is run zero-shot, as released, with the decode settings recorded in its run.json. Hypotheses and references go through the same published normalizer. WER and CER are corpus-level. Every number carries a 95% utterance-level percentile bootstrap interval. The common slice is a fixed, seeded, dialect-stratified sample of about 1,000 utterances per set so that every system is compared on identical audio. Full details, the normalizer code, the manifests and every per-utterance output are in the repository.

Scope: open-weight models and global vendors only. Vendors domiciled in the GCC appear only after written opt-in. This page reports measured values and makes no other claims.
