# Harfiyyan (حرفياً)

A reproducible Arabic ASR leaderboard: open models and commercial APIs on one table, scored with Elm-compatible WER, variant-tolerant WER, and entity/numeral probes, every number with a 95% confidence interval, per dataset and per dialect.

Status: v0 in progress. Results tables are generated from `results/` by `scripts/build.py`; nothing in this file is hand-typed.
