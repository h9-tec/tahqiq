Tahqiq

A reproducible leaderboard for Arabic speech recognition. Open-weight models run through one harness on six public test sets; every number carries a 95% confidence interval. Tahqiq is the most exact style of recitation, where every letter is given its full right; in everyday Arabic it means verification.

Submit a model

Any public Hugging Face model with a Transformers-native ASR architecture: Whisper, wav2vec2 and HuBERT CTC fine-tunes, Qwen3-ASR, Cohere Transcribe, Voxtral. Repositories that need trust_remote_code, NeMo checkpoints, and weights above 24 GB wait for a maintainer. The submission is evaluated on the common slice (about 1,000 utterances per set) on Hugging Face compute, usually within the hour, and the result is posted in its request thread.

The only permission requested is to open a discussion in the request queue on your behalf.

Method

Every system is run zero-shot, as released, with the decode settings recorded in its run.json. Hypotheses and references go through the same published normalizer. WER and CER are corpus-level. Every number carries a 95% utterance-level percentile bootstrap interval (2,000 resamples). Test sets are the six public ones used by Elm's Open Universal Arabic ASR Leaderboard, reconstructed utterance for utterance from Elm's manifests; audio stays on our machine, only outputs are published. The common slice is a fixed, seeded, dialect-stratified sample of about 1,000 utterances per set.

Normalizers. elm is a line-for-line port of Elm's, tested for string equality against the original, so that column is comparable to Elm's board. tolerant adds NFC, tatweel, alef/alef-maksura/ta-marbuta/hamza folding and a published spelling-variant table.

Probes. Numeral: references with digits or an unambiguous spoken number word, scored on digit-string equality with number words mapped on both sides. Entity: reference PERS/LOC/ORG spans from CAMeL-Lab's NER tagger (score ≥ 0.8, published side file), scored by containment after tolerant normalization.

Scope. Open-weight models and global vendors only. Vendors domiciled in the GCC appear only after written opt-in. This page reports measured values and makes no other claims. Full details, code, manifests and every per-utterance output: github.com/h9-tec/tahqiq and tahqiq-results.
